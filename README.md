# Dashboard de Brecha de Género - Bolivia, Ecuador, Perú

## 📊 Descripción
Dashboard interactivo para analizar la brecha de género en el mercado laboral de Bolivia, Ecuador y Perú.

## 🚀 Características
- Análisis de ingresos por país y sexo
- Comparación de niveles educativos
- Distribución por área geográfica (urbano/rural)
- Análisis por sector económico
- Visualizaciones interactivas

```bash
# Clonar el repositorio
git clone [URL-de-tu-repositorio]

# Instalar dependencias
